# 🔖 GoHOME cherish

Pokémon HOME以前のポケモンを、大切にしまっておくための場所。

Nintendo DS・ニンテンドー3DSのポケモン作品を、ソフトごとに記録・整理できるブラウザツールです。
Pokémon HOMEへのお引っ越し管理にも、昔のソフトのコレクション記録にも使えます。

## これは何？

GoHOME cherish は、Nintendo Switch以前のポケモン作品（DS〜3DS）を対象にした、
ブラウザだけで動くポケモンコレクション管理ツールです。

2027年2月26日の『ポケモンバンク』サービス終了に向けて、

- どのソフトに、どのポケモンがいるのか
- 誰をPokémon HOMEへ連れていくのか
- どこまで図鑑を集めたのか
- 大切な個体や配布ポケモンをどこに保存しているのか

といった情報を整理し、思い出のポケモンたちのお引っ越しを手助けするために作りました。

でも、Pokémon HOMEに移す予定がない人にも使ってもらえるように作っています。

「懐かしいソフトの中身を、ただ大事に一覧しておきたい」
「昔一緒に冒険したポケモンたちの記録を残したい」

そんな使い方も、このアプリのれっきとした目的のひとつです。

## 🌐 For non-Japanese users

GoHOME cherish is a browser-based collection manager for Pokémon games on Nintendo DS and Nintendo 3DS.

It helps you keep track of the Pokémon stored in each of your games, plan transfers to Pokémon HOME, and preserve a record of your old collections.

The app currently supports Japanese only, but contributions for additional languages are very welcome!

All data is stored locally in your browser and is not uploaded to a server.

Translations welcome!

- ブラック／ホワイト／ブラック2／ホワイト2

- オメガルビー／アルファサファイア
- サン／ムーン／ウルトラサン／ウルトラムーン

### 主な機能

- 🎮 **ソフト管理** — 同じ作品を含め、手持ちのソフトを何本でも登録して個別に管理
- 📔 **図鑑管理** — 地方図鑑・全国図鑑の所持状況、色違い・HOME移送対象・お気に入りを記録
- 🧬 **個体情報メモ** — ニックネーム・性格・特性・ボール・リボンなどを1匹ずつ記録
- 📝 **周回メモ** — 厳選・周回中のソフトごとに、色違いカウンターや持ち物などを管理
- 🎁 **配布図鑑** — 過去の公式配布ポケモンを一覧し、受け取り済み／ふしぎなおくりものカード保存済みを記録
- 💾 **バックアップ** — JSON／TXT／MD／CSV形式でデータを書き出し・読み込み

### ソフトは何本でも登録できます

同じ作品を複数本持っている場合や、周回用ROMがある場合も、
1本ずつ別々のソフトとして登録・管理できます。

## 使ってみる

スマートフォンやPCのブラウザで、以下のURLを開くだけで使えます。
インストールやアカウント登録は必要ありません。

**https://gohome-cherish.github.io/Pocket/**

### 🔒 データについて

入力したデータは、すべて使用中の端末・ブラウザ内（IndexedDB）に保存されます。

入力したコレクション情報が、GoHOME cherishのサーバーへ送信されることはありません。

ただし、

- ブラウザのサイトデータを削除した場合
- ブラウザを変更した場合
- 端末を変更・初期化した場合
- ブラウザ側の保存データに問題が起きた場合

などには、保存内容が失われる可能性があります。

大切な記録は、定期的に「書き出し・読み込み」からJSONバックアップを保存しておくことをおすすめします。

**注意**
GoHOME cherish自体に、ポケモンを別のソフトやPokémon HOMEへ転送する機能はありません。
ポケモンのコレクション記録・整理・移送計画を手助けするためのツールです。

## 一緒に、お引っ越し頑張りましょう！

『ポケモンバンク』は、**2027年2月26日（金）12:00（日本時間）**をもってサービス終了予定です。

それに伴い、『ポケモンバンク』から『Pokémon HOME』へポケモンを送る「ひっこし」機能も終了予定です。

思い出のポケモンたちをPokémon HOMEへ連れていきたい方は、
期限より少し余裕をもって、お引っ越しを進めることをおすすめします。

大切なポケモンたちを、悔いのないようお引っ越しできますように。

そしてもちろん、お引っ越しを予定していない方にも——

GoHOME cherishは、**「過去作管理アプリ」**として、そのままずっと使っていただけます。
